# codeOS on...

### Apple M1/M2 芯片

[Asahi Alarm](https://asahi-alarm.org/) 是基于 [Asahi Linux](https://asahilinux.org/) 的 Apple M1/M2 版 Arch。花一些功夫可以在上面跑 codeOS。见[用户编写的指南](https://github.com/omarchy-mac/omarchy-mac)。

### Apple 虚拟机

也可以在 Parallels VM 里装 codeOS。过程比较麻烦，但也有[用户指南](https://github.com/basecamp/omarchy/discussions/452)。

### VirtualBox

VirtualBox 是流行的虚拟机运行器。[里面也能跑 codeOS](https://github.com/basecamp/omarchy/discussions/176)。但性能可能不太好。

### Windows 11 上的 VMware Workstation

另一款流行的 Windows 虚拟机运行器。[codeOS 也有人在上面装过](https://github.com/basecamp/omarchy/discussions/572)。

### Steam Deck

Steam Deck 跑的就是 Arch，意味着你的 Steam Deck 也能跑 codeOS。Altynbek Orumbayev 写了[完整的安装脚本和说明](https://github.com/aorumbayev/deckarchy)。多酷啊！

### NixOS

codeOS 本质是 Arch + Hyprland，但 Henry Sipp 把 setup 的精华[移植到了 NixOS](https://github.com/henrysipp/omarchy-nix)。如果你已经被 nix 洗脑了，这是个不错的起点。它可能跟上最新 codeOS 变化也可能不，但不管怎样挺酷！

### 其他配置！

如果你在默认以外的配置上跑 codeOS，来我们社区 Discord 的 #omarchy-on-other 频道交流。
