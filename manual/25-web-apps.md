# Web 应用

可以用 codeOS 菜单（`Super + Space`）里的 _Install > Web App_ 添加自己的 web 应用。它会让你填应用名、应用 URL、图标 URL（如果无法通过 favicon 获取的话）。在 [Dashboard Icons](https://dashboardicons.com) 上可以找到很多流行 web 应用的精美 PNG 图标。

之后它们可以通过应用启动器（`Super + Space`）访问，使用漂亮的无边框 web 应用窗口。

想删除 web 应用，在 codeOS 菜单里 _Remove > Web App_ 即可。

建议先在常规浏览器里登录所有账号再用 web 应用快捷方式。薄壳窗口框架和 1password 配合不好，所以提前登录更省事。

这些 web 应用的键盘快捷键都可以在 `~/.config/hypr/bindings.lua` 里改。

在 web 应用里时，用 `Shift + Alt + L` 把当前 URL 复制到剪贴板。

默认 codeOS 已经预装了一批 web 应用：

## HEY

[HEY](https://www.hey.com/) 是邮件和日历服务，对厌倦 Gmail、Outlook 或 Apple Mail 的人来说是很好的替代。它由 [37signals](https://37signals.com/) 制作——codeOS 也起源于那里。

按 `Super + Shift + E` 启动 HEY 邮件，`Super + Shift + Alt + E` 直接写新邮件，`Super + Shift + C` 启动 HEY 日历。

## Basecamp

[Basecamp](https://basecamp.com/) 是项目管理服务，帮助小团队更快前进、取得更多进展。不用把 Trello、Slack、Asana、Notion 各种东西拼在一起，Basecamp 一站式搞定。同样由 [37signals](https://37signals.com/) 制作。

通过应用启动器（`Super + Space`）启动 Basecamp。

## ChatGPT

[ChatGPT](https://chatgpt.com) 是世界上最流行的 AI 聊天机器人。

按 `Super + Shift + A` 启动 ChatGPT。

## Grok

[Grok](https://grok.com) 是 xAI 的聊天机器人。

按 `Super + Shift + Alt + A` 启动 Grok。

## WhatsApp

[WhatsApp](https://www.whatsapp.com/) 是世界上最流行的消息服务之一，网页版对 Linux 来说是很好的选择。

按 `Super + Shift + Alt + G` 启动 WhatsApp。

## Google 应用

Google Messages、Google Photos、Google Maps 和 Google Contacts 也都以 web 应用形式预装。

按 `Super + Shift + Ctrl + G` 启动 Google Messages，`Super + Shift + P` 启动 Google Photos，`Super + Shift + S` 启动 Google Maps。Google Contacts 通过应用启动器（`Super + Space`）访问。

## X

X 是新闻爆发的地方。

按 `Super + Shift + X` 启动 X，`Super + Shift + Alt + X` 直接写新帖子。

## YouTube

[YouTube](https://youtube.com/) 是世界上最流行的视频平台。

按 `Super + Shift + Y` 启动 YouTube。

## Zoom

[Zoom](https://zoom.us/) 是美国最流行的视频会议系统，全球连接质量好。不开付费账户也能开 40 分钟会议。codeOS 封装了 Zoom 的 web 客户端，zoom 会议链接会直接在里面打开。

通过应用启动器（`Super + Space`）启动 Zoom。

## Discord

[Discord](https://discord.com/) 是大多数游戏和开源社区聚集的地方，包括 [codeOS 自己的](https://discord.gg/tXFUdasqhY)。

通过应用启动器（`Super + Space`）启动 Discord。
