# 顶栏

屏幕顶部那条横条就是 codeOS 顶栏。它不是一个额外拼接的状态栏，而是 codeOS Shell 的一部分——同一个长期运行的 Quickshell 进程还负责绘制菜单、通知、OSD 弹出提示和锁屏。这就是为什么它能和其他东西完美同步主题，也是为什么点一下面板能瞬间打开而不是启动新应用。

它也是桌面上唯一常驻的元素，所以值得了解这些小图标都在做什么。

## 默认有什么

顶栏分三段。左边是 codeOS 标志（菜单启动器）和工作区指示器。中间是状态指示器、时钟、键盘布局、天气和 codeOS 更新徽章。右边是系统托盘、AI Agent、蓝牙、网络、音频、显示和电源。

其中有些只有在有内容时才出现。键盘布局只在你配置了多个时才显示。更新徽章只在有 codeOS 更新等待时出现。AI Agent 图标则在 codeOS 第一次检测到机器上有 AI 编码使用时出现（详见 [AI](17-ai.md)）。

## 点击试试

几乎每个小组件都对左键、右键和中键有不同反应，还有几个支持滚动。这是很多人容易忽略的部分——右键和中键才藏着好东西。

| 小组件 | 左键 | 右键 | 中键 / 滚动 |
| --- | --- | --- | --- |
| 菜单 | codeOS 菜单 | 新建终端 | — |
| 工作区 | 跳到该工作区 | — | — |
| 时钟 | 日历弹出 | 切换标签格式 | 中键：时区选择 |
| 天气 | 预报弹出 | 全屏天气通知 | 中键：刷新 |
| 音频 | 音频面板 | 静音 | 中键：面板 · 滚动：音量 |
| 麦克风 | 静音麦克风 | — | 中键：音频面板 · 滚动：输入音量 |
| 网络 | 网络面板 | — | — |
| 蓝牙 | 蓝牙面板 | 切换开关 | — |
| 显示 | 显示面板 | — | 滚动：亮度 |
| 电源 | 电源面板 | 切换电量百分比 | — |
| 媒体 | 播放/暂停 | 封面弹出 | 中键：下一首 · 滚动：上一首/下一首 |
| AI Agent | Agent 面板 | 启动你的 Agent | 中键：下一个订阅 |
| 托盘 | 悬停展开抽屉 | 右键箭头管理 | — |
| codeOS 更新 | 运行更新 | — | — |

表格里不是所有东西默认都在你的顶栏上。媒体小组件（MPRIS 正在播放，滚动显示曲目和歌手）和麦克风小组件都内置但默认关闭——需要的话可以加，下文有说明。

## 面板

点击顶栏图标会打开面板，它是一个正规的弹出窗口，带滑块、列表和键盘导航，不是简单的工具提示。每个面板也对应一个快捷键，这样你不用去瞄准那个 16 像素的小图标：

| 快捷键 | 面板 |
| --- | --- |
| `Super + Ctrl + A` | 音频 |
| `Super + Ctrl + W` | 网络 |
| `Super + Ctrl + B` | 蓝牙 |
| `Super + Ctrl + D` | 显示 |
| `Super + Ctrl + P` | 电源 |
| `Super + Ctrl + Alt + D` | 日历 |
| `Super + Ctrl + 1-9` | 切换右侧第 n 个面板 |

这些面板不是只读展示——你在里面真正操作：

- **音频** 有主音量滑块、输出设备选择器和每个应用独立的混音器，这样你可以只把那个浏览器标签页静音而不影响其他。
- **网络** 扫描 Wi-Fi、显示信号强度、连接网络，还能让你选 DNS 提供商。
- **蓝牙** 列出你的设备，支持连接/断开和电量显示。
- **电源** 显示电池状态、切换电源模式（会记住电池和交流电各自的选择），还显示一些系统信息。
- **显示** 带亮度滑块、文字大小、显示器缩放预设，以及——当你有多屏时——每个屏幕独立控制。详见 [显示器](33-monitors.md) 了解更多。
- **时钟** 打开月历视图，显示 ISO 周数并支持月份切换。

每个面板都支持键盘操作：方向键移动、回车激活、Tab 跳到相邻面板、Esc 关闭。

`Super + Ctrl + 1-9` 从右段左往右数面板（跳过托盘，因为它没有独立面板），所以数字和你看到的图标对应。

### Tailscale 和 Dropbox

安装了对应服务后（通过 **Install → Service**），顶栏还会多两个小组件，都值得了解，因为它们不止显示状态。

**Tailscale** 面板可以连接/断开 tailnet、切换账户、选择出口节点（你自己的机器和 Mullvad 区域都在列表里）。它还可以浏览你的机器——选中一台后按 `s` 通过 Taildrop 发送文件，这是把文件传到手机或另一台笔记本最快的方式。`c` 复制机器 IP，`n` 复制名字，`d` 复制完整 DNS 名。每台机器的行上也有发送按钮，想点就点。在终端里对应的是 `omarchy tailscale send <machine> [file...]`。

**Dropbox** 面板处理登录、显示已用存储空间、列出最近同步的文件。

卸载服务后，对应的小组件也会从顶栏消失。

## 指示器

中间那一小簇是指示器小组件。它们是各种开启模式的状态图标：勿扰、夜灯、队列中的 [提醒](09-reminders.md)、活跃的录屏、保持清醒、[听写](11-text-extraction-dictation.md)。模式开启时点亮，平时藏起来——鼠标悬停顶栏中间就能看到未激活的那些。点击指示器切换该模式。

如果想让它们始终可见，给小组件的 `alwaysShow` 设为 `true`。如果只关心其中几个，在 `items` 里列出你想要的：`["Dnd", "Reminder", "NightLight"]`。你可以有多个指示器小组件，这样不同区域可以显示不同的子集。

## 调整顶栏位置

顶栏可以自己配，不用打开配置文件来移动。

抓住中间附近的空白区域，拖向其他屏幕边缘，顶栏就会移过去——左、右、上、下都可以，每个小组件会自动适配（竖条会退化成紧凑图标模式）。点击并按住也能开始拖拽。双击同一块空白区域切换透明度。拖动任何小组件可以重新排序或移到另一段。

如果更喜欢用菜单，**Style → Menu Bar** 里有位置和透明度选项。

同样的操作也有命令行版本，这对 [点文件](31-dotfiles.md) 同步很有用：

```bash
omarchy bar position bottom
omarchy bar transparent toggle
omarchy bar move omarchy.clock --section center --index 0
omarchy bar set omarchy.clock format "HH:mm"
omarchy bar defaults          # 恢复到默认布局
```

要彻底添加或移除小组件，用插件命令。`omarchy plugin list` 会列出 Shell 知道的所有小组件及其 id，然后：

```bash
omarchy plugin enable omarchy.media --section center
omarchy plugin disable omarchy.weather
```

## 隐藏顶栏

`Super + Shift + Space` 可以把顶栏关掉再打开，不会杀掉 Shell——面板和快捷键继续工作，只是多了像素空间。菜单里也有，在 **Trigger → Toggle → Menu Bar**。

## 配置文件

所有这些都存放在 `~/.config/omarchy/shell.json` 的 `bar` 字段下。这里是一个精简版本：

```json
{
  "version": 1,
  "bar": {
    "position": "top",
    "transparent": false,
    "centerAnchor": "omarchy.clock",
    "layout": {
      "left": [{ "id": "omarchy.menu" }, { "id": "omarchy.workspaces" }],
      "center": [{ "id": "omarchy.clock", "format": "HH:mm" }],
      "right": [{ "id": "omarchy.audio" }, { "id": "omarchy.power" }]
    }
  }
}
```

每个小组件都是三段布局数组中的一条，它的设置就内联在这条上——没有单独的设置文件，也没有 `config` 子对象。时钟的 `format`、`formatAlt`（右键切换到的格式）和 `verticalFormat` 都直接写在 `{ "id": "omarchy.clock" }` 这条上。

`centerAnchor` 指定了中间段中被固定在屏幕正中心的那个小组件，其他的在它两边展开。这就是为什么即使天气和更新徽章出现又消失，时钟还能保持在正中。设为空字符串的话，中间列表就作为整体居中。

有个规则值得记住：**一旦你有了自己的 `shell.json`，它就是权威的**。在你自定义之前，Shell 读的是 codeOS 的默认文件。从你拖动一个小组件、运行 `omarchy bar` 或手动编辑文件的那一刻起，你就接管了——不会做深度合并，所以未来 codeOS 新版本里的默认小组件不会自动出现在你的顶栏上。想恢复干净状态，随时运行 `omarchy bar defaults`。

同一个文件还在顶层（`bar` 字段之外）存了你的空闲计时设置：`idle.screensaver` 和 `idle.lock`，都是进入空闲后的秒数。默认屏保 150 秒启动，锁屏 300 秒。
