# 字体

codeOS 默认用 JetBrainsMono Nerd Font 同时作为终端和系统字体。

 ![fonts-jetbrainsmono](images/fonts-jetbrainsmono.webp)

可以通过 codeOS 菜单（`Super + Space`）的 _Style > Font_ 换掉。那里设置的等宽字体会应用到所有地方：终端、顶栏以及其他需要的地方。

通过 codeOS 菜单的 _Install > Style > Font_ 可以一键安装其他流行编程字体：Cascadia Mono、Meslo LG Mono、Fira Code、Victor Code、Bitstream Vera Mono 和 Iosevka，全部是 Nerd Font 版本，这样顶栏和终端里的字形正常显示。装完后在 _Style > Font_ 里选。
