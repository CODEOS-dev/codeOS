# AI

codeOS 把 AI 编码 Agent 当作一等公民，但不会替你选。相反，每个主流编码 Agent CLI 都预装成懒加载的启动器。启动器是放在 `~/.local/bin/` 里的微型 [mise](https://mise.jdx.dev/) 管理桩代码，第一次真正运行某个时才会下载。调用以下任意一个并按提示认证：

| 命令    | Agent                                                            |
|------------|------------------------------------------------------------------|
| `claude`   | [Claude Code](https://code.claude.com/docs/en/overview)          |
| `codex`    | [OpenAI Codex](https://github.com/openai/codex)                  |
| `opencode` | [OpenCode](https://opencode.ai/)                                 |
| `agy`      | [Google Antigravity CLI](https://github.com/google-antigravity/antigravity-cli) |
| `copilot`  | [GitHub Copilot CLI](https://github.com/github/copilot-cli)      |
| `crush`    | [Crush](https://github.com/charmbracelet/crush)                  |
| `grok`     | Grok CLI from xAI                                                |
| `pi`       | [Mario Zechner's Pi](https://github.com/badlogic/pi-mono)        |
| `omp`      | [Oh My Pi](https://github.com/can1357/oh-my-pi)                  |
| `ori`      | [Ori](https://openrouter.ai/docs/guides/ori/harness), OpenRouter 的 harness |
| `hermes`   | [Hermes](https://hermes-agent.nousresearch.com/), Nous Research 的 agent  |
| `muse`     | [Muse Code](https://dev.meta.ai), Meta 的编码 Agent           |
| `cursor-agent` | [Cursor CLI](https://cursor.com/cli)                         |

`ori` 比较特殊：它让其他 harness 跑在 OpenRouter 的整个模型目录上，所以 `ori claude`、`ori codex` 或 `ori opencode` 会在你指定的模型上启动那些 Agent，`ori code` 则是 Ori 自己的 Agent。

要包装额外的 CLI，运行 `omarchy-mise-install <package> [command-name]`。当你运行 `omarchy update`（或 `mup` 别名）时，这些桩代码和其他 mise 管理的东西一起更新。

### 默认 Agent

用 `omarchy default agent <name>` 或 codeOS 菜单里的 _Setup > Defaults > Agent_（`Super + Space`）选默认 Agent。如果这个 Agent 还没安装，选它会先安装。全新 codeOS 会通过一次性通知邀请你做这个选择。

[Muse Code](https://dev.meta.ai)（Meta 的 `muse`）和其他 Agent 一样预装了 mise 桩代码。把它设为默认后，会通过 mise 的 HTTP 后端安装 Meta 官方启动器。启动器会验证并更新适合你机器的原生二进制。

选好后，`Super + Shift + Ctrl + A` 在专用终端窗口里启动默认 Agent（或弹出选择器如果你还没选）。也可以直接启动任务：`omarchy agent prompt "Review this project"`。这样启动的 Agent 会在自动批准模式下无人值守运行——准备好让它们真的动手做事！而且因为 Agent 不会对 home 目录记住信任，从 `$HOME` 启动时会自动跳到 `~/Work`。

还有终端快捷方式：`a` 在当前终端内联运行默认 Agent，`c`、`cx`、`cy` 直接启动 OpenCode、Claude Code 和 Codex（同样自动批准模式）。主题变更也会同步到 Agent：Claude Code、Pi、OpenCode 和 Hermes（安装 Hermes Desktop 后）会跟着你切换的 codeOS 主题走。

### Agent 面板

codeOS 第一次检测到机器上有 AI 编码使用时，顶栏会出现一个 Agent 图标（之前不显示）。背后的面板统一跟踪所有订阅：你的套餐、5 小时会话和每周限额的使用百分比（或剩余预付费余额）、按天和按模型的 token 使用量。Claude Code、Codex 和 Fireworks 默认都覆盖。

左键顶栏图标打开面板，右键启动默认 Agent。使用记录每 15 分钟由 `omarchy agent usage-update` 重新生成，面板还能通过同步文件夹合并其他机器的使用数据。完整设置见 `$OMARCHY_PATH/shell/plugins/agents/` 下的 README。

### 崩溃诊断

codeOS 监听 systemd-coredump 监控进程崩溃。有进程段错误时，你会收到"进程崩溃"通知——点击它，崩溃信息会连同 codeOS 的 diagnose-crash skill 一起交给你的默认 Agent，引导 Agent 从 core dump 中查明事实并决定是否上报上游。也可以手动运行 `omarchy agent crash <pid>` 处理 `coredumpctl list` 里列出的任意 PID。

默认开启监听。在 _Trigger > Toggle > Crash Capture_（或 `omarchy toggle crash-capture`）下关闭后通知就停了；手动 `omarchy agent crash <pid>` 仍然可用。

崩溃也可以按程序单独静音——诊断结束时会给你这个选项。`omarchy crash mute hyprland` 只停止那个程序的通知，`omarchy crash mute hyprland off` 恢复，单独运行 `omarchy crash mute` 列出已静音的。既接受二进制名也接受路径，所以 `omarchy crash mute /usr/bin/hyprland` 效果一样。名字里有空格的要加引号，如 `omarchy crash mute 'Some App'`。其他程序照常通知，静音的程序照样崩溃——只是隐藏了提示，不解决问题。

### 桌面应用

_Install > AI_ 菜单还有几个图形 AI 应用：ChatGPT 桌面版、和 xAI 模型聊天的 Grok Bot、Hermes Desktop、OpenClaw、Perplexity 桌面版。

重点说 Hermes Desktop，因为一台机器上永远只有一个 Hermes。它只在自己 commit 构建的运行时上运行，所以首次启动会在 `~/.hermes` 下安装自己的运行时，花几分钟并显示进度。之后终端的 `hermes` 命令和默认 Agent 都用这个，不管你先装哪个。安装后还会把 codeOS 主题作为一个名为 `omarchy` 的皮肤交给 Hermes，切换主题时所有 Hermes 表面都跟着走；不想跟的话在 Hermes 的外观设置里或用 `/skin` 选别的，codeOS 不再干涉。通过 _Remove > AI_ 卸载应用会带走那个运行时，你的聊天、记忆和 Hermes 为自己写的 skill 会保留——它会问你要不要一起删，默认不删。

OpenClaw 的桌面体验是它的 Control UI，作为 web 应用打开，背后是自己的本地网关。OpenClaw 的更新通过 codeOS 的包更新来——跳过 Control UI 自己的"Update Gateway"按钮，它会尝试写入包管理的安装目录然后失败。通过 _Remove > AI_ 卸载 OpenClaw 会带走网关服务和应用，然后问你要不要删 `~/.openclaw`，那里存着你的聊天、凭据和 OpenClaw 自己下载的插件运行时；默认保留。

### 本地 LLM

codeOS 推荐两种方式运行本地 LLM：LM Studio 和 Ollama。LM Studio 提供 GUI 来查找开源模型、安装和运行，上手很方便。Ollama 用 CLI 做同样的事。对本地模型新手来说，建议从 LM Studio 开始。在 codeOS 菜单的 _Install > AI_ 下安装。

### codeOS Skill

Agent skill 帮助 AI 用特定方式调用特定工具，codeOS 自带默认 skill 来定制系统——比如调整 Hyprland 配置、改顶栏、甚至从零创建新主题。它被符号链接到 Claude Code（`~/.claude/skills`）、Codex（`~/.codex/skills`）、Pi（`~/.pi/agent/skills`）、Antigravity（`~/.gemini/config/skills`）、Hermes（`~/.hermes/skills` 和每个 `~/.hermes/profiles/*/skills`）以及通用的 `~/.agents/skills` 目录，所以大多数 harness 自动就用得上。

但把这个 skill 当作实验性功能。不同模型效果不同。最好先在 plan 模式下跑，看看 Agent 打算改什么。如果 Agent 搞砸了，准备好回滚甚至运行 `omarchy reinstall configs`。
