# 快捷键

用 `Super + K` 可以查看所有主要键盘绑定（Tmux 绑定用 `Super + Alt + K`，Herdr 绑定用 `Super + Ctrl + K`）。

## 导航

| 快捷键                  | 功能              |
| ----------------------- | --------------------- |
| `Super + Space`           | codeOS 菜单（应用和其他一切）    |
| `Super + Alt + Space` | 应用菜单 |
| `Super + Escape` | 系统菜单（挂起、重启等）  |
| `Super + Ctrl + L` | 锁定电脑 |
| `Super + W` 或 `Super + Q` | 关闭窗口             |
| `Ctrl + Alt + Del` | 关闭所有窗口 |
| `Super + T`               | 在平铺/浮动之间切换窗口             |
| `Super + J` | 切换窗口位置（水平/垂直） |
| `Super + O`               | 将窗口弹出为粘性浮动 |
| `Super + L`               | 在 Dwindle 和 Scroll 布局之间切换 |
| `Super + P`               | 切换伪窗口样式（自然 vs 拉伸） |
| `Super + F`                 | 全屏              |
| `Super + Alt + F`                 | 全宽              |
| `Super + Ctrl + F`                 | 在窗口内全屏              |
| `Super + 1/2/3/4`         | 跳到指定工作区     |
| `Super + Tab` | 跳到下一个工作区 |
| `Super + Shift + Tab` | 跳到上一个工作区 |
| `Super + Ctrl + Tab` | 跳到上一个工作区 |
| `Super + Shift + 1/2/3/4` | 移动窗口到指定工作区 |
| `Super + Shift + Alt + 1/2/3/4` | 移动窗口到指定工作区但不跟随 |
| `Super + S` / `Super + Grave` | 切换 Scratchpad |
| `Super + Alt + S` / `Super + Shift + Grave` | 移动窗口到 Scratchpad |
| `Super + Shift + Alt + Arrows` | 移动工作区到方向对应的显示器 |
| `Super + Arrow`  | 将焦点移到箭头方向的窗口              |
| `Super + Shift + Arrow`  | 与箭头方向的窗口交换位置     |
| `Super + Minus` | 向左扩展窗口 |
| `Super + Equal` | 向左收缩窗口 |
| `Super + Shift + Minus` | 向上收缩窗口 |
| `Super + Shift + Equal` | 向下扩展窗口 |
| `Super + Alt + Minus/Equal` | 更小步长的调整 |
| `Super + Ctrl + Minus/Equal` | 更大步长的调整 |
| `Super + Alt + Home` | 保存窗口宽度 |
| `Super + Home` | 恢复已保存的窗口宽度 |
| `Super + Left Mouse` | 拖动窗口 |
| `Super + Right Mouse` | 调整窗口大小 |
| `Super + Scroll Wheel` | 在工作区间滚动切换 |
| `Super + G`               | 切换窗口分组      |
| `Super + Alt + G`               | 将窗口移出分组      |
| `Super + Alt + Tab`               | 在分组内的窗口间循环      |
| `Super + Alt + Shift + Tab`               | 在分组内的窗口间反向循环      |
| `Super + Alt + 1/2/3/4/5`               | 跳到分组内指定窗口      |
| `Super + Alt + Arrow`  | 将窗口移入箭头方向的分组  |
| `Super + Ctrl + Left/Right`  | 平铺分组内的窗口间移动 |
| `Super + Ctrl + Z` | 屏幕放大（重复继续放大） |
| `Super + Ctrl + Alt + Z` | 屏幕完全缩小 |
| `Super + /` | 向前切换显示器缩放选项 |
| `Super + Alt + /` | 向后切换显示器缩放选项 |
| `Alt + Tab` | 当前工作区窗口向前循环 |
| `Alt + Shift + Tab` | 当前工作区窗口向后循环 |
| `Ctrl + Alt + Tab`| 显示器焦点向前循环 |
| `Ctrl + Alt + Shift + Tab`| 显示器焦点向后循环 |

## 统一剪贴板

| 快捷键                  | 功能              |
| ----------------------- | --------------------- |
| `Super + C`           | 复制    |
| `Super + X`           | 剪切（终端内除外）    |
| `Super + V`           | 粘贴    |
| `Super + Ctrl + V`           | 剪贴板历史    |

通常在 Linux 上，你需要 `Ctrl + Shift + C/V` 在终端里复制粘贴，`Ctrl + C/V` 在其他地方。codeOS 的统一剪贴板快捷键在任何地方都能用。

## 截图/录屏

| 快捷键              | 功能                       |
| ------------------- | ------------------------------ |
| `Super + Ctrl + C` | 捕获菜单（给没有 PrintScr 键的键盘用） |
| `Print Screen`            | 截图                      |
| `Alt + Print Screen`            | 录屏                     |
| `Super + Print Screen` | 取色器 |
| `Super + Ctrl + Print Screen` | 文本提取到剪贴板 |
| `Super + Alt + [` | 录屏时缩小摄像头覆盖层 |
| `Super + Alt + ]` | 录屏时放大摄像头覆盖层 |
| `Alt + Shift + L` | 从 WebApp 或 Chromium 复制当前 URL |
| `Alt + Shift + D` | 将当前页面的视频下载到 `~/Videos` |
| `Super + Ctrl + X` | 开始/停止听写（需要 _Install > AI > Dictation_） |
| `F9` | 按住说话听写（需要 _Install > AI > Dictation_） |

录屏时，快捷键会先问你要不要录音频，然后开始录制。再按一次停止。详见 [截屏与录屏](12-screenshots-recording.md)。

所有捕获选项也可以在 codeOS 菜单（`Super + Space`）的 _Trigger > Capture_ 下找到。

## Tmux

前缀键是 `Ctrl + Space`（`Ctrl + B` 也可用）。可以在 `~/.config/tmux/tmux.conf` 里改。

### 分屏

| 快捷键                  | 功能              |
| ----------------------- | --------------------- |
| `Prefix + v` | 右侧分屏（垂直） |
| `Prefix + h` | 下方分屏（水平） |
| `Prefix + x` | 关闭分屏 |
| `Prefix + z` | 切换分屏全屏 |
| `Alt + Enter` | 下方分屏（无需前缀） |
| `Alt + Shift + Enter` | 右侧分屏（无需前缀） |
| `Alt + Escape` | 关闭分屏（无需前缀） |
| `Ctrl + Alt + Arrows` | 在分屏间移动 |
| `Ctrl + Alt + Shift + Arrows` | 调整分屏大小 |

### 窗口

| 快捷键                  | 功能              |
| ----------------------- | --------------------- |
| `Prefix + c` | 新建窗口 |
| `Prefix + k` | 关闭窗口 |
| `Prefix + r` | 重命名窗口 |
| `Alt + 1-9` | 跳到指定窗口 |
| `Alt + Arrow Left/Right` | 在窗口间移动 |
| `Alt + Shift + Arrow Left/Right` | 将窗口左/右移动 |

### 会话

| 快捷键                  | 功能              |
| ----------------------- | --------------------- |
| `Prefix + C` | 新建会话 |
| `Prefix + K` | 关闭会话 |
| `Prefix + R` | 重命名会话 |
| `Prefix + N` | 下一个会话 |
| `Prefix + P` | 上一个会话 |
| `Alt + Arrow Up/Down` | 在会话间移动 |
| `Prefix + s` | 列出会话 |
| `Prefix + d` | 脱离会话 |

### 复制模式（vi 风格）

| 快捷键                  | 功能              |
| ----------------------- | --------------------- |
| `Prefix + [` | 进入复制模式 |
| `v` | 开始选择（复制模式下） |
| `y` | 复制选中内容（复制模式下） |

### 通用

| 快捷键                  | 功能              |
| ----------------------- | --------------------- |
| `Prefix + q` | 重新加载配置 |
| `Prefix + ?` | 显示 Tmux 键位绑定 |
| `Prefix + :` | 命令提示 |

### Tmux 布局函数

这些函数必须在 Tmux 会话内运行。

| 命令 | 功能 |
| ------- | -------- |
| `tdl <ai> [<second_ai>]` | 创建含编辑器、AI 和终端的开发布局 |
| `tdlm <ai> [<second_ai>]` | 按子目录创建开发布局 |
| `tsl <count> <command>` | 创建多窗口 swarm 布局 |
