# 通知提醒

通过快捷键可以快速查看日期时间、电池状态和当前天气。

### 日期与时间

`Super + Ctrl + Alt + T`

 ![notice-datetime](images/notice-datetime.webp)

### 天气

`Super + Ctrl + Alt + W`

 ![notice-weather](images/notice-weather.webp)

位置通过 IP 地址检测，通常够用但不总是准确。可以用 `omarchy weather location --set Malibu` 固定位置，或者更精确地加坐标：`omarchy weather location --set Malibu 34.0259,-118.7798`。单独运行 `omarchy weather location` 看看系统认为你在哪，`--clear` 恢复自动检测。

### 电池

`Super + Ctrl + Alt + B`
