# 背景

每个主题自带一组背景，你也可以在 `~/.config/omarchy/backgrounds/[theme]` 里放自己的。想给 nord 主题加一张额外背景，就把文件放到 `~/.config/omarchy/backgrounds/nord`。

最简单的方式是打开 codeOS 菜单的 _Install > Style > Background_。它会打开该主题的背景文件夹。按 `Super + Shift + F` 再开一个文件管理器，找到你的背景图，复制过去。现在它就会出现在 `Super + Ctrl + Space` 切换的背景选择里了。

背景可以是视频也可以是静态图。把 `mp4`、`m4v`、`mov`、`webm`、`mkv` 或 `avi` 文件放到同一文件夹，它会和图片一起出现并循环播放。只有第一台显示器的壁纸会播放视频的音轨，通过默认音频输出以系统音量播放，锁屏保持静音。当视频不可见时自动停止播放——全屏窗口盖住显示器、屏保启动、锁屏黑屏时——但视频壁纸比静态壁纸耗电得多，而且每台显示器独立解码。

可以在 https://github.com/dharmx/walls 找到大量精选的酷背景。
