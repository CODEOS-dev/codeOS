# 欢迎来到 codeOS！

codeOS 是一个基于 [Arch](https://archlinux.org/) 的 [omakase](https://manuals.omamix.org/3/omacom/76/omakase-computing) Linux 发行版，使用 Tiling Window Manager [Hyprland](https://hypr.land/) 和桌面构建套件 [Quickshell](https://quickshell.org/)。它预装了现代、精明的计算机用户能够立即投入高效工作所需的一切。从 [Neovim](https://neovim.io/)（顺便一提）到 Chromium，从 [Obsidian](https://obsidian.md/) 到 LibreOffice，从 Kdenlive 到 OBS Studio。甚至还有一个复古 Winamp 风格的音乐播放器！

但这不仅仅是一堆预装软件的堆砌。它是一个兼顾美学与生产力的完整系统。因为一个 _美丽的_ 系统就是一个 _有动力的_ 系统，而生产力始终 [源自动力](https://world.hey.com/dhh/beautiful-motivations-6fef7c73)。这里没有任何臃肿的东西：只有我自己在用的一切。

诚然，要欣赏像 codeOS 这样以 TUI 为主、主题丰富、采用 tiling window manager 的系统之美，确实需要培养一些审美。但这正是你来这里的原因，对吧？体验一点舒适区之外的东西？开启一段小小的冒险，探索一种与计算机协作的新方式？希望如此。

codeOS 不像 Windows，也不像 macOS。它不追求尽可能熟悉。它追求的是美丽和 _更好_。拥抱它的 Linux 特质吧。手动编辑一些配置文件？当然。重度使用终端？绝对的。

让我们从基础开始吧。
