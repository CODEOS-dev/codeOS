# 主题

codeOS 内置了二十二款精美的主题。你可以在 codeOS 菜单（`Super + Space`）中通过 _Style > Theme_ 进行选择，或者用 `Super + Ctrl + Shift + Space` 直接打开主题选择器。

每个主题都会为桌面、终端、neovim、activity 界面（btop）、Chromium 以及整个 codeOS shell 统一样式：包括顶栏、菜单、通知、OSD 和锁屏。（Obsidian 需要在应用内部通过 _Appearance > Themes_ 手动选择 codeOS 主题）。

每个主题都配有一组背景图片，可以用 `Super + Ctrl + Space` 在这些图片之间切换。

你可以在[额外主题页面](https://codeos.org/themes/)找到更多主题，或者[制作自己的主题](43-making-your-own-theme.md)。
